# WorldStructures

Плагин структур, элитных мобов, мини-боссов и наград для Paper 1.21.1 и Java 21.

Сборка и тесты: `mvn clean verify`. Готовый плагин: `target/WorldStructures.jar`.

Основные настройки находятся в `src/main/resources/config.yml`. Команды и разрешения описаны в `src/main/resources/plugin.yml`.

Проект выделен из [SMPCristalix](https://github.com/QuerlyFF/SMPCristalix) с сохранением истории изменений плагина.
